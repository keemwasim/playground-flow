# design system audit, 2026-07-22 (v3.1)

Scope: tokens/, components/, assets/, styles.css, README.md, SKILL.md, CHANGELOG.md. Prototype .dc.html files untouched. Every claim below is labeled verified (checked mechanically or by reading the resulting file) or unproven (judgment or not machine-checkable).

## inventory count
94 files audited (verified by file listing):
- tokens/: 7 css files (colors, typography, surfaces, motion, layout, components, a11y) plus styles.css (imports only, all 7 imported, verified)
- components/: 23 components as triplets (.jsx / .d.ts / .prompt.md), 69 files
- assets/: 14 files (5 logo/icon svg, 2 retired svg, 7 world images)
- docs: README.md, SKILL.md, CHANGELOG.md

## removed
- surfaces.css: duplicate `--glass-night-bg` (defined twice in the same file). One definition kept inside a single labeled world-side glass block. Why: rule 3, duplicate definitions. Verified.
- surfaces.css: `--glass-edge-top` (legacy alias, referenced nowhere in the system or the archived pages, grep-verified). Verified.
- typography.css: `--font-mono` legacy alias, referenced nowhere, and raw monospace is banned anyway. Verified.
- layout.css: `--z-toast` (unused alias of --z-notice, and "toast" violates the world-word naming rule). Verified.
- components.css: `--toast-width` (same value already defined as `--notice-w` in layout.css, same value under two names) and `--toast-dwell` (renamed `--arrival-dwell`, world-word naming). Verified.
- motion.css: duplicate `@keyframes pgFadeIn` (defined twice, second copy removed). Verified.
- Chip.jsx: glass recipe (backdrop blur, translucent fill, borders) removed, replaced by the flat well tokens. Why: ink returns 1b, chips are flat wells, chosen chip is ink, and the old code referenced `--line-mid` and `--text-on-ink` which do not exist anywhere. Verified.
- Homecoming.jsx SealedNote: perforated stub and wax medallion removed (referenced four `--seal-*` tokens that were never defined, and CHANGELOG v3 already ruled "stub/wax-mark removed, plain paper card"). The card is now plain paper. Verified.
- Notice.jsx: ES module imports (`import { Logo } from './Logo.jsx'`) removed. The loader convention is window.PG and Logo.jsx/Sprite.jsx export nothing, so these imports could never resolve. Siblings are now read off window.PG at render time. Verified against the loader comment in every file, runtime behavior unproven.
- Globe.jsx: color sea, warm lands, blue glow, blue halo, white glints, clouds, and the `clouds` prop. Why: owner ruling, the globe is ink etching, monochrome, and blue glow is a cool tint on chrome. Geometry (land blobs, spin, souls) kept. Verified in code, look unproven.
- app-icon.svg: vertical white-to-gray linear gradient background flattened to solid white. Why: named old-Apple tell. Geometry untouched. Verified.
- Desk.jsx: folder glyph gradient fill plus inset bevel highlight, NoteDoc white-to-gray vertical gradient. Why: never gradient, never bevel on paper. Flattened to solid steps. Verified.
- Kept, not removed (deliberate): night ramp (`--night-0..3`, `--star`, `--bg-night`) and the color-globe tokens now live in single clearly labeled DEPRECATED blocks (colors.css, surfaces.css, components.css) because the archived night draft (Playground Screens.dc.html, screens.html) and the spec pages still reference them (grep-verified). `--on-night-1..3` were moved out of the deprecated block and relabeled world-side text, because live components (Society, a11y focus ring) legitimately use them over world imagery.

- components.css, `--notice-radius-activity` comment said 22, actual value (radius-menu) is 26. Comment corrected. Verified.
- Glass.jsx: Sheet and Menu were glass (blur plus translucent fills). Now opaque paper using the sheet/menu tokens that already said paper. Scrim now uses `--scrim-modal` instead of a third hardcoded scrim value. Glass itself is kept but documented as world-imagery-only, and now composes `--glass-edge` per the v3 lensing recipe. Verified.

- Desk.jsx FolderChip: glass chip to paper chip. FriendDiamond eyes were #191C2E (cool navy tint on chrome), now ink-3, and its white border now uses `--sticker-border`. Verified.
- Boot.jsx: hardcoded desktop backdrop now uses `--surface-desktop` (newly defined, see added). Verified.

- Chip.jsx Segmented: hardcoded track/thumb values now use the `--seg-*` tokens (visuals unchanged, thumb ruling intact). Verified.
- typography.css: `--text-button` comment claimed "raised-white v3", now ink returns v4. Verified.
- Notice.jsx and Homecoming.jsx and others: all components now resolve every token they reference. Post-fix cross-reference scan found zero var() references to undefined tokens (was 6: --line-mid, --text-on-ink, 4 --seal-*). Verified mechanically.
