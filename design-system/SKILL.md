Read the README.md file within this skill, and explore the other available files (tokens/, components/, assets/).
If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, copy assets and read the rules here to become an expert in designing with this brand.
Key laws: one mode, light, every app surface is opaque paper (white cards, hairline rings at 5 percent, flat wells). Ink returns buttons: solid ink primary, radius 12, no shadows on controls, chosen chip is ink. Lensing glass ONLY over world imagery (the tear, world photos). The globe has three ruled treatments in Globe.jsx (eclipse default, souls, relief), monochrome, never any grid or meridian lines. Icons are inlined Lucide paths, never span-built glyphs. Sora display / Manrope everything / Unbounded wordmark only. No emoji, no italics, no serifs. The tear is invisible except during crossings. The companion always breathes. World words in copy, never software words.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
