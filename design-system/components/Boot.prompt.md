Brand motion. The logo's counter-hole doubles as an eye — it blinks every 4.6s (pgLogoBlink) and the mark breathes. Use AnimatedLogo anywhere the brand should feel alive (boot, empty states); use static Logo in chrome (menubar, headers).

```jsx
<AnimatedLogo size={52} hole="#F7F7F9" />
<BootScreen caption="waking the house…" />
```
