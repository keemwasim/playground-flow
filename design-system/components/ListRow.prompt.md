One row shape everywhere. Leading is a world object (diamond, doc, tile) or a Lucide icon, never an icon font.

```jsx
<ListRow leading={<FriendDiamond />} title="Moth" sub="archivist · met twice"
  trailing={<Button variant="ghost">Find again</Button>} />
<ListRow leading={<NoteDoc />} title="Three papers on sleep debt" sub="by Sol" chevron last />
```
